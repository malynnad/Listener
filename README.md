# Listener

本地音乐、B 站音源、网络电台，放在同一个播放器里。Flutter + mpv 实现，Android 与 macOS 双端。

| | 能做什么 |
|---|---|
| **本地** | 扫描文件夹建曲库，读标签和内嵌封面，按曲名 / 艺人 / 专辑秒搜 |
| **B 站** | 搜索视频直接抽音轨播放，扫码登录后按账号权限拿最高码率，可下载到本地 |
| **电台** | 全球网络电台，热门榜 / 关键词 / 按国家筛选，可收藏 |

三个来源共用一条播放队列，可以混着听。

## 安装

### Android

- 要求 **Android 7.0（API 24）及以上**，目前只提供 **64 位 arm64** 包（约 38 MB）
- 安装包在任一仓库的 Releases 页下载 `app-release.apk`：
  [Gitee](https://gitee.com/dannylam/listener/releases) ·
  [GitCode](https://gitcode.com/DannyLam/Listener/releases) ·
  [GitHub](https://github.com/mallynad/Listener/releases)
- 若 Releases 暂时没有产物，可按 [开发与构建](docs/DEVELOPMENT.md) 自行编译；`android/key.properties` 缺失时会自动回退 debug 签名，不影响本地使用
- 首次安装需要在系统里允许"安装未知来源应用"

### macOS

暂未提供预编译包，需本地构建，且**必须装完整 Xcode**（只有 Command Line Tools 时 `xcodebuild` 不可用）：

```bash
flutter pub get && flutter run -d macos --release
```

## 上手三步

1. **本地页**点「扫描手机音乐」（macOS 上是「添加文件夹」），授权后等扫描完成
2. **B站页**点右上「扫码登录」，用 B 站 App 扫一下——不登录多数音轨只有 64K
3. **电台页**默认就是热门榜，点任意一个台直接开播

底部（宽屏是左侧）三个标签页切换：**本地 / B站 / 电台**。播放栏常驻在底部，切页不打断播放。

## 本地音乐

**导入**

| 平台 | 做法 | 说明 |
|---|---|---|
| Android | 「扫描手机音乐」 | 授予媒体权限后扫描 Music、Download、Documents、Podcasts、Ringtones，以及网易云 / QQ 音乐 / 酷狗的下载目录 |
| Android | 「添加文件」 | 手动多选，适合临时试听。选中的是系统缓存副本，别当长期曲库 |
| macOS | 「添加文件夹」 | 任选目录，递归扫描 |

**操作**

- 点一行：从这一首开始播，同时把当前列表整体设为队列（后续自动接下去）
- 行尾 `+`：只把这一首加进队列，不打断正在播的歌
- 顶部搜索框：按曲名、艺人、专辑实时过滤，不用回车
- 「重新扫描」：换了文件夹或补了新歌后点一下
- 「播放全部」：整个列表入队从头播

**格式**：MP3、FLAC、M4A、AAC、WAV、OGG、OPUS、WMA、APE、ALAC、AIFF。
扫描时会读标签和内嵌封面，结果缓存在本地，重启不必重新解析。

## B 站听歌

**登录（建议做）**

点右上「扫码登录」→ 用手机 B 站 App 扫二维码并在手机上确认。
未登录时接口只给 64K 音轨；登录后按账号权限自动选最高的一档（132K / 192K / Dolby / Hi-Res FLAC）。
登录态存在系统钥匙串里，不用反复登录；点右上角头像可「退出登录」。

**搜索与播放**

在搜索框输入歌名、翻唱、现场或纯音乐，回车。每个结果右侧有三个操作：

| 图标 | 作用 |
|---|---|
| 点一行 | 解析音轨并立即播放 |
| `+` | 加入队列 |
| `↓` | 下载音轨到本地，下载过的会变成勾选状态 |

**下载位置**

- Android：`Android/data/com.listener.player/files/downloads`
  这个目录在系统文件管理器里通常看不到，点页面右上角的文件夹图标会把完整路径提示出来
- macOS：`~/Downloads/Listener`，点文件夹图标直接打开

Android 不内置 ffmpeg，DASH 音轨是分片 MP4 直接存成 `.m4a`。mpv / VLC / ExoPlayer 都能正常播，个别老旧系统播放器可能不认。

## 电台

- 默认加载热门榜（约 100 个台），右上刷新按钮重新拉取
- 搜索框直接输英文关键词最有效，例如 `jazz`、`lofi`、`BBC`
- 「国家」下拉用于按国家筛选，选「全部」回到不限
- 点行尾星标收藏，右上星形按钮切换「只看收藏」，收藏存在本地

电台是**直播流**，和三件事相关：

1. 播放栏不显示进度条，显示「直播中」，也不能拖动
2. 断流后不会自动跳下一个台，而是停在原地提示「电台连接已断开，重新点击该台即可继续」——这是刻意的，避免出现"一直在换台关不掉"的观感
3. 想彻底静音请用播放栏的**停止按钮**，不是暂停

## 播放栏

| 控件 | 说明 |
|---|---|
| 封面 / 标题 | 显示当前曲目与来源标签（本地 / B站 / 电台） |
| 播放 / 暂停 | 未装载任何曲目时点它，会装载队列里的第一首 |
| 上一首 / 下一首 | 在队列里移动 |
| **停止** | 真正释放音频输出。电台换台前、想彻底安静时用它 |
| 循环 | 三态循环：关闭 → 列表循环 → 单曲循环 |
| 随机 | 独立开关，与循环模式叠加生效 |
| 队列 | 打开队列面板，可跳播、清空 |

队列会持久化，下次启动恢复上次的曲目列表——但**保持暂停状态**，不会一开门就出声。

## 常见问题

**安卓扫描不到歌？**
`扫描手机音乐` 只扫约定的那几个目录（分区存储下无法全盘遍历）。歌放在别处就先挪进 `Music/`，或者用「添加文件」手动选。权限被拒的话按提示去 设置 → 应用 → Listener → 权限 打开「音乐和音频」。

**B 站搜到了但放不出来？**
- 提示 403 / 链接已过期：音源地址有有效期，重新搜一次即可
- 提示 -352 / -412：触发风控，等几分钟或降低操作频率
- 一直 64K：没登录，或者该视频本身只有 64K 音轨

**电台点了没反应 / 一直转圈？**
单个台连不上很常见（很多台是个人架设的）。换一个台试试，或点右上刷新。连续多个台都不行，检查网络是否拦截了境外请求。

**为什么重启后不自动播放？**
设计如此。恢复队列但保持暂停，避免插上耳机或开会时突然出声，点一下播放即可。

**为什么没有通知栏 / 锁屏控制？**
当前版本未接入 `audio_service`。退到后台仍会继续播放，但要切歌得回到应用内。

**暂停和停止有什么区别？**
暂停保留播放位置，一点就接着放；停止会释放音频输出、进度归零，电台场景下用它才能真正静音。

## 数据与隐私

- 曲库索引、收藏、播放队列全部存在本机，不上传任何服务器
- B 站登录 Cookie（`SESSDATA` 等）通过 `flutter_secure_storage` 存入系统钥匙串，不写日志、不入库
- 电台数据来自 [radio-browser.info](https://www.radio-browser.info/) 的公开接口，请求带可识别的 User-Agent 并做频率节流
- 应用不内置、不分发任何受版权保护的内容；B 站下载产物只落在本机
